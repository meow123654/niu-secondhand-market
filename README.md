# 宜大拾物｜校園二手交易平台

手機與電腦皆可使用的 Flask、SQLite 校園市集專題原型。

## 啟動

```powershell
py -m pip install -r requirements.txt
py server.py
```

電腦瀏覽 `http://localhost:8000`。手機連上同一個 Wi-Fi 後，在電腦執行 `ipconfig` 找到 IPv4 位址，再於手機瀏覽 `http://電腦IPv4位址:8000`。兩台裝置必須使用相同伺服器網址，聊天、商品和媒體才能共用。

## 功能

- 各科系商品版：含使用者提供圖片中看得到的 15 個科系與系碼；課本／商品可指定科系，依科系瀏覽。
- 買家與賣家聊天：含訊息收件匣；訊息寫入 SQLite，瀏覽器每 2.5 秒更新對話；聊天也可傳照片或影片。
- 手機媒體：商品與聊天欄位支援手機拍照及從相簿選取照片／影片；商品媒體上限 80 MB。
- 商品搜尋、分類、價格排序、收藏、刊登、編輯、刪除與交易狀態管理。
- 商品、訊息和媒體存在 `data/marketplace.sqlite3` 與 `uploads/`。

## 專題原型的範圍

登入目前是展示帳號（暱稱、信箱、科系），沒有串接宜大校務帳號或權限驗證。聊天適合同一 Wi-Fi 上的課堂展示；尚未加入 HTTPS、帳號驗證、濫用防護或正式部署設定，請勿直接公開在網際網路上。若手機瀏覽器不開啟相機，可使用「選擇檔案」從相簿上傳；公開正式使用時需部署至 HTTPS 網址。
